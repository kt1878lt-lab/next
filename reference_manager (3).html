📡 Webhook 自動推送設定

設定 Webhook URL 後，每次新增或編輯文獻時，系統會自動將資料推送到您指定的網址。
適用於整合 Zapier、Make、n8n 等自動化工具。

儲存後，新增/編輯文獻時將自動發送資料到此網址

📋 資料格式說明（JSON Schema）

系統會以 POST 請求發送以下格式的 JSON 資料： 

{
  "reference_content": "引用文獻內容",
  "journal_title": "期刊標題",
  "original_journal_title": "原期刊標題",
  "journal_apa": "期刊 APA 格式",
  "original_apa": "原期刊 APA 格式",
  "citation_topic": "引用主題（關鍵字）",
  "project_affiliation": "所屬計畫名稱",
  "is_cited": true,
  "created_at": "2024-01-01T12:00:00.000Z",
  "updated_at": "2024-01-01T12:00:00.000Z"
}

🔧 JavaScript Fetch 範例

fetch(webhookURL, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    reference_content: "文獻內容",
    journal_title: "期刊標題",
    original_journal_title: "原期刊標題",
    journal_apa: "APA 格式",
    original_apa: "原文 APA",
    citation_topic: "自我效能、教師自主",
    project_affiliation: "計畫名稱",
    is_cited: true,
    created_at: new Date().toISOString(),
    updated_at: new Date().toISOString()
  })
});
