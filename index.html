🔗 Webhook 自動化設定

設定 Webhook URL 後,每次儲存或更新文獻時,系統會自動將資料發送到指定的位址,方便整合第三方自動化服務(如 Make.com、Zapier、n8n 等)。

請輸入完整的 Webhook 接收端點 URL

📋 發送的 JSON 資料格式

每次儲存文獻時,系統會以 POST 方法將以下 JSON 格式的資料發送到您設定的 Webhook URL: 

{
  "reference_id": 1234567890,
  "reference_content": "引用的文獻內容全文",
  "journal_title": "期刊標題",
  "original_journal_title": "原期刊標題",
  "journal_apa": "期刊 APA 格式引用",
  "original_journal_apa": "原期刊 APA 格式引用",
  "citation_topics": "氣候變遷, 永續發展, 環境保護",
  "project_id": 9876543210,
  "project_name": "所屬計畫名稱",
  "is_cited": true,
  "created_at": "2026-05-26T10:30:00.000Z",
  "updated_at": "2026-05-26T10:30:00.000Z"
}
🔑 欄位說明 (Key Definitions)
  • reference_id: 文獻唯一識別碼 (Number)
  • reference_content: 引用文獻內容 (String)
  • journal_title: 期刊標題 (String)
  • original_journal_title: 原期刊標題 (String)
  • journal_apa: 期刊 APA 格式 (String)
  • original_journal_apa: 原期刊 APA 格式 (String)
  • citation_topics: 引用主題關鍵字,逗號分隔 (String)
  • project_id: 所屬計畫 ID (Number | null)
  • project_name: 所屬計畫名稱 (String)
  • is_cited: 是否已引用 (Boolean)
  • created_at: 建立時間 ISO 8601 格式 (String)
  • updated_at: 更新時間 ISO 8601 格式 (String)

📦 匯出資料檔案

將所有文獻資料匯出為 CSV 或 JSON 格式,方便備份或在其他系統中使用。
